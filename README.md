# Audiowizard Workspace — PWA

Рабочий прототип PWA-приложения по ТЗ (`SPECIFICATION.md` + `SRS.md`): внутренняя CRM + клиентский портал для сервиса обработки контента. Полностью самодостаточный фронтенд без сборки и внешних зависимостей: vanilla JS, дизайн-система на CSS-переменных, демо-данные, localStorage + IndexedDB, Service Worker.

## Запуск

**Вариант 1 — просто открыть.** Двойной клик по `index.html`. Всё работает (вход, заказы, чаты, темы, черновики). Service Worker в `file://` недоступен — это ограничение браузеров, не ошибка.

**Вариант 2 — как настоящий PWA (рекомендуется):**

```bash
cd audiowizard-workspace
python3 -m http.server 8080
# открыть http://localhost:8080
```

При HTTPS (или localhost) браузер предложит установку приложения; Service Worker кеширует оболочку и работает офлайн.

## Демо-вход

| Роль | Логин | Пароль | Что видно |
|---|---|---|---|
| Администратор | `admin` | `admin123` | всё + аудит, ниши, бекапы, статистика функций |
| Главный менеджер | `top` | `top123` | всё, без голосований |
| Менеджер | `manager` | `manager123` | полная CRM |
| Исполнитель | `maria` | `executor123` | свои заказы, сокращённый дедлайн, чаты |
| Заказчик (портал) | `client` | `client123` | свои заказы, счётчик оплаты |

На экране входа есть кнопки демо-входа для всех ролей (переключатель «Сотрудник / Клиентский портал»).

## Что реализовано

- **Splash screen** с переливающимися градиентами → авторизация с вкладками сотрудник/портал, «глазик», «запомнить», восстановление.
- **Роли:** admin / top_manager / manager / executor / client — меню, данные и права различаются (гостевой режим, невидимка админа, приватность платежей для исполнителя).
- **Заказы (оптимизировано под большие объёмы):** скелетон-загрузка при входе на вкладку, прогрессивная подгрузка порциями по 80 строк при прокрутке (IntersectionObserver), делегирование событий — выбор строк и массовые операции не перерисовывают страницу; таблица помещается без горизонтального скролла (7 компактных колонок, `table-layout:fixed`), на узких экранах превращается в карточки; колонка «Дата начала работ» в форме, детали и импорте. Фильтры (статусы/ниша/проект/архив), сортировка, живой поиск, контекстное меню по правому клику, копирование ID, итоговое подтверждение, автосохранение черновика (IndexedDB, 5 с), предоплата 0–100% с проверкой договора <50%, запрет скачивания, файлы с автоопределением длительности аудио.
- **Правила статусов из ТЗ:** возврат в `waiting` запрещён всем; удаление только в `draft`/`waiting`; `done→любой` аннулирует начисления с подтверждением; переход в `done` начисляет заработок исполнителям и требует чекбокса принятия работы (для исполнителя — чекбокс о правах на материалы, ст. 146/183 УК РФ).
- **Оплата:** прогресс оплаты для заказчика/менеджера/админа; исполнитель видит только «Оплачено/Не оплачено»; «оплатить всем» / индивидуально.
- **Клиенты и исполнители:** карточки со статистикой, квалификация (звёзды) и комментарии с «голосованием»/без для admin и top, чёрный список, передача менеджеру, личные пометки, реквизиты, рабочие статусы, онлайн-точки.
- **Чаты:** корпоративный, по заказу, менеджеров, группа специализации, чат компании; реакции, опросы с голосованием, эмодзи, модерация, «не беспокоить», массовое сообщение клиентам, автомодерация телефонов, режим невидимки для админа.
- **Идеи:** лайки, топ-выделение, видимость по группам ролей, модерация.
- **Тикеты:** создание из заказа и меню, статусы new → in_progress → resolved.
- **Канбан:** личные и общие доски, drag-and-drop, связка карточек со статусами заказов.
- **Импорт/экспорт:** drag-and-drop, прогресс, логи на русском, дубликаты, правила «если в комментарии ТЕКСТ → скидка/менеджер/статус» с тестером; экспорт CSV/XLSX по нишам. **XLSX читается напрямую** (свой ZIP/XML-парсер, без зависимостей): выбор листа с автоопределением типа (клиенты/исполнители/заказы), маппинг по заголовкам, статусы RU → статусы системы, даты Excel (serial) и дедлайны «до 04.04.19 23:00», исполнители «6, 34, 35» и «12, 5-2500» по номерам строк. **CSV: автоопределение кодировки** UTF-8 / Windows-1251 (+ ручной выбор) — кириллица из русского Excel больше не превращается в кракозябры.
- **Калькулятор:** ввод выражений с клавиатуры (живой результат, история), услуги по нишам с маржой; услуги/цены/маржа управляются админом и менеджерами (Настройки → Калькулятор и услуги).
- **Дашборды по ролям:** выручка, спарклайн, статусы-донат, ТОП исполнителей/клиентов, использование функций (админ), сокращённый дедлайн исполнителя (−15%).
- **Настройки:** профиль с загрузкой аватара → WebP, 7 тем (системная по умолчанию), уведомления и отписка от рассылок, сессии + «выйти на всех устройствах», 2FA-заглушка, горячие клавиши (Ctrl+K, Ctrl+N, Ctrl+,, Ctrl+Shift+T), справка/документы/FAQ, «О приложении» с историей версий и проверкой обновлений, бекапы и сброс с обязательным бекапом (админ).
- **PWA:** manifest, Service Worker (кеш оболочки, фоновое обновление, офлайн), version.json + уведомление «обновить сейчас/позже», офлайн-индикатор и очередь операций, cookie-баннер, обучающий тур, палетка команд (Ctrl+K), центр уведомлений, стилизованные 403/404/500/DDoS-страницы.
- **ИИ-сервисы (v0.9.3):**
  - **ИИ-стенограммы** — пайплайн распознавания с прогрессом, диаризация спикеров (переименование), **караоке-синхрон**: подсветка бежит по словам вместе с аудио, есть волновая дорожка с перемоткой; **неуверенные слова подчёркнуты пунктиром** — клик открывает список альтернатив с уверенностью, замена сохраняется в профиле; ручная правка сегментов, поиск, экспорт TXT/SRT, загрузка своего аудио (тайминги масштабируются), прикрепление результата к заказу.
  - **ИИ-копирайтинг** — генерация текста по брифу (тема × тон × длина) с тремя вариантами и эффектом печати, рерайт с подсчётом правок, саммари, заголовки; копирование, скачивание, прикрепление к заказу.
  - **ИИ-переводы** — RU → EN/DE/ES с сохранением структуры (абзацы, переносы, списки), показ покрытия словаря, «вставить результат в источник», скачивание и прикрепление к заказу.
  - Счётчик минут подписки ИИ (демо-лимит 180 мин/мес). Демо-движок локальный: данные стенограммы генерируются `tools/make_ai_assets.py` вместе с аудио — тайминги слов совпадают со звуком точно.


## Соответствие ТЗ и границы демо

Прототип покрывает клиентскую часть Must-функций из SRS (FR-AUTH, FR-ORDER, FR-CLIENT, FR-EXECUTOR, FR-OFFLINE, FR-DASH, FR-TICKET, FR-IDEA, FR-CHAT, FR-KANBAN, FR-IMPORT, FR-ADMIN-001/002/003/009 и др.) в режиме одного браузера. Серверная часть ТЗ (PHP 8.1 + MySQL, Redis, WebSocket `/ws`, AES-256 на сервере, SMTP, реальный импорт XLSX) — следующий этап; в демо её место занимают детерминированные демо-данные и localStorage/IndexedDB. Функции «в разработке» из ТЗ (2FA, тендеры, NDA-подписание, чаевые, краудфандинг, A/B и т.д.) оформлены фирменной заглушкой «Функция в разработке».

## Продакшн-режим

Администратор (Настройки → «Демо-режим и версии») может отключить демо-данные: все демонстрационные записи скрываются во всех разделах, демо-вход убирается с экрана входа, а разделы меню настраиваются чекбоксами («Разделы меню в продакшене»). Данные при этом не удаляются — включение тумблера возвращает всё.

## Импорт / экспорт

Импорт XLSX и CSV (UTF-8 / Windows-1251), «Вся таблица» — авто-определение типов листов по заголовкам; правила импорта (условия с regex: менеджер, скидка по триггер-словам). Экспорт: клиенты / исполнители / заказы по отдельности или «Вся таблица» единой книгой XLSX с листами; журнал импорта выгружается отдельным CSV (админ).
