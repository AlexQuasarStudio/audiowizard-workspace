# Тесты

Браузерные проверки прототипа. Без сборки и без package.json: скрипты запускаются
напрямую через Node, Playwright берётся из окружения.

## Запуск

```bash
node tests/serve.js            # статический сервер на http://localhost:8777
node tests/smoke.js            # в другом терминале
```

Если сервер уже поднят на другом порту:

```bash
BASE_URL=http://localhost:8000 node tests/smoke.js
```

Playwright ищется в таком порядке: `PLAYWRIGHT_MODULE`, локальный `playwright`,
общий набор навыков MultiTool (`~/.config/gigatool/skills/web-automation/scripts/lib.js`).

## Что проверяет smoke

- номер сборки в `index.html` совпадает с `version.json`;
- демо-вход администратора и отрисовка оболочки;
- каждый раздел меню открывается и рисует содержимое;
- демо-аудио ИИ не грузится на старте и подключается только в разделе стенограмм;
- окна детализаций дашборда (выручка, активные заказы, приток) одной высоты;
- нет ошибок в консоли и `pageerror`.

Код возврата `1` — есть провалившаяся проверка, подробности в JSON.

## Сервер

`tests/serve.js` — обычная раздача статики с поддержкой `Range` (нужна аудио)
и запретом выхода за пределы проекта. Порт задаётся аргументом: `node tests/serve.js 8080`.
